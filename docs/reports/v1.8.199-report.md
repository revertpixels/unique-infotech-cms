# Release v1.8.199 Review Report — Optional TXN ID, Two Kids Profile Docs & Unified Kids Admission Popups

**Scope:** Shared Payment Popup (`payment-popup.js` — optional TXN ID for both Youth & Kids; Kids Paid Admission success popup), Unique Kids Admissions (`school-admissions.html`, `school-admissions.page.js`), Unique Kids Student Profile Documents (`student-profile.page.js`), and Unique Kids Admission Slip (`school-admission-receipt.page.js`, `school-receipt-pdf.js`). ## 1. What Changed (Plain English)

1. **Transaction / Reference ID -> Optional Again (Youth & Kids)**
   - Updated `public/js/components/payment-popup.js`:
     - Non-cash modes (`UPI`, `Card`, `Bank Transfer`, `Cheque`) enable the Transaction / Reference ID field with label `(Optional)`, `required = false`, and never block saving if left empty.
     - `Cash` stays disabled with `(N/A for Cash)`.
     - Removed the required-field error check and inline invalid state from `saveBtn.onclick`.

2. **Kids Documents -> Strictly "Passport Photo" & "Student Signature" Only**
   - **Kids Admission Form (`public/pages/school-admissions.html`):** Relabeled the two upload boxes clearly as **Passport Photo** and **Student Signature** (no Date of Birth Proof or Academic Marksheet inputs exist or upload for Kids).
   - **Kids Student Profile (`public/js/pages/student-profile.page.js`):**
     - When viewing a Kids profile (`ctx === 'school'`), **Documents** tab description updates to `Passport photo & student signature` and `renderDocumentsTab()` renders only `Passport Photo` and `Student Signature` cards, skipping `dobProof`, `marksheet`, and extra docs in `docsCache`.
     - Existing legacy `dobProof` / `marksheet` documents in Firestore are **left untouched** (not deleted, simply hidden from the Kids UI).
     - Youth Centre profiles (`ctx === 'youth'`) still show all 4 document slots (`Date of Birth Proof`, `Academic Marksheet`, `Passport Photo`, `Student Signature`) and any extra docs unchanged.
   - **Kids Admission Slip (`school-admission-receipt.page.js`, `school-receipt.js`, `school-receipt-pdf.js`):** Already only render Photo & Signature (no DOB proof / marksheet).

3. **Kids "No payment" Confirm Popup + Unified "Admission successful" Popup + Admission Slip Polish**
   - **Confirm admission popup (`public/js/pages/school-admissions.page.js`):** Clicking **Admit student** under `No payment` (or `₹0` admission charge) validates all inputs, uploads, and duplicate phone+level check first, then opens a **"Confirm admission"** popup showing: Student name, Level, Batch, Admission date, `Admission fee: ₹0 (No payment)`, the formatted exemption reason (`formatNoPaymentReason`), and `Monthly fee ₹X will be billed from <month>`.
     - Clicking **Cancel** closes the popup cleanly, saves nothing to Firestore, and keeps the filled form open.
     - Clicking **Confirm admission** writes the student, docs, Aadhaar, admission payment doc, and opens initial bills atomically, then opens the **"Admission successful"** popup.
   - **Unified "Admission successful" popup (`public/js/components/payment-popup.js` + `public/css/pages/pay-fees.css`):**
     - Exported `promptKidsAdmissionSuccess(...)` matching `.pf-success-modal`, with a CSS animated green checkmark (`@keyframes pfSuccessPop` & `pfCheckDraw`), title **"Admission successful"**, summary box, and **4 action buttons** in a responsive 2x2 grid:
       1. **View admission slip** -> `#/school-admissions/<studentDocId>/receipt`
       2. **Print** -> `#/school-admissions/<studentDocId>/receipt?print=1`
       3. **Open profile** -> `#/students/<studentDocId>`
       4. **Admit another** -> stays on `#/school-students` and opens a fresh blank form (`openForm(null)`)
     - Both **Paid Kids admissions** (inside `payment-popup.js` when `!isUpgrade`) and **No-payment Kids admissions** (`school-admissions.page.js`) now open **"Admission successful"**. Monthly fee payments and Level Upgrades still use **"Payment Recorded!"** (`promptOpenReceipt`).
   - **Kids No-payment Admission Slip (`public/js/pages/school-admission-receipt.page.js`, `public/js/utils/school-receipt-pdf.js`):**
     - Shows `No payment – <reason>` (with en-dash `–`) and `₹0` on the HTML slip (`Rs. 0.00` in Roboto PDF), and omits any **Payment mode** or **TXN ID** rows when `d.paymentMode === 'none'` or `d.actualAmountReceived <= 0`.
