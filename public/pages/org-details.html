How to manually delete backups from Firebase Console

Backups are auto-pruned to keep the last 5 normal backups and last 2 safety backups. You can also delete any backup directly in Firebase Console without breaking this page:

  1. Confirm the status above shows no active maintenance lock.
  2. In Firebase Storage, open system-backups/<your-uid>/ and delete the unwanted backup-<id>.json file.
  3. Optionally open Firestore Database → _system_backup_manifests and delete the matching <id> document (note: once its manifest doc is deleted, even a local copy of that backup file cannot be restored).
  4. Click Refresh Status above; missing Storage files drop from this list cleanly.
